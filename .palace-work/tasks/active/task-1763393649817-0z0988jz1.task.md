# Objective

## Objective
Build complete email subscription functionality for the landing page newsletter signup form in the Footer component.

## Tasks to Complete

1. **Database Schema Setup**
   - Create a new table `email_subscriptions` using libSQL/Turso (@libsql/client is already installed)
   - Schema fields:
     - id (primary key, auto-increment)
     - email (unique, not null)
     - subscribed_at (timestamp, default now)
     - status (enum: 'active', 'unsubscribed', 'bounced')
     - source (text, e.g., 'footer_form')
     - ip_address (text, optional)
   - Add appropriate indexes for email lookups

2. **API Endpoint Creation**
   - Create `/src/app/api/subscribe/route.ts` (Next.js 15 App Router API route)
   - Handle POST requests with email validation
   - Validate email format using regex or library
   - Check for duplicate subscriptions
   - Insert new subscription into database
   - Return appropriate success/error responses
   - Add rate limiting to prevent spam (optional but recommended)

3. **Frontend Integration**
   - Update Footer component (`src/components/Footer.tsx`)
   - Connect newsletter form (currently at lines 220-274) to API endpoint
   - Add loading state during submission
   - Display success message on successful subscription
   - Display error messages for:
     - Invalid email format
     - Already subscribed
     - Network errors
   - Clear form on successful submission

4. **Validation & Error Handling**
   - Client-side email validation before submission
   - Server-side validation and sanitization
   - Proper error messages for different failure scenarios
   - Database connection error handling
   - Add TypeScript types for request/response

## Technical Context
- Database: Using @libsql/client (Turso/libSQL) - already in package.json
- Framework: Next.js 15 with App Router
- Current Footer form: Has email input and subscribe button but no backend connection
- Styling: Uses inline styles matching the design system (cyan accents #00C2FF)
